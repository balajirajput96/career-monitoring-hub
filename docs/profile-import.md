## Runtime usage

The persisted `education`, `verifiedExperience`, and `factsSource` fields are the verified profile context used by the deterministic scorer. Education and structured experience contribute only bounded evidence when the job text explicitly contains matching terms; they never create employment history, credentials, or eligibility claims. Resume uploads remain user-provided artifacts in private storage, and no resume content is synthesized from unverified assumptions.
